# 硬性强制禁令
禁止B站任何布局、禁止赛博霓虹、禁止二次元粉蓝配色、禁止全屏大圆卡片、禁止浮夸流光动效、禁止市面影视网站通用模板、禁止过度装饰性元素

# 项目概述
从零原创开发极简轻奢质感影视风视频播放网站完整前端项目
技术栈: Vite + Vue3 + Naive UI + UnoCSS + 定制ArtPlayer播放器
后端: SpringBoot微服务架构(通过Gateway网关统一访问)
设计理念: Less is More - 以留白、材质、光影塑造高级感

# 1. 后端对接固定规则

## 1.1 接口配置
- 网关基础地址: http://localhost:8080
- 服务路由规则:
  - 用户服务: /user/*
  - 视频服务: /video/*
  - 互动服务: /interact/* (包含like/collect/comment/coin/follow)
  - 推荐服务: /recommend/*

## 1.2 鉴权规则
- 全局请求头: User-Token: <token>
- Token存储: localStorage('userToken')
- JWT有效期: 24小时,过期返回code=401

## 1.3 权限管控
- Vue Router4路由守卫拦截未登录访问
- 角色区分: 
  - 普通用户(role=0): 浏览、播放、互动
  - 管理员(role=1): 额外拥有后台管理权限(/admin/*)
- 未登录禁止: 播放详情页、收藏、点赞、投币、评论
- 按钮级权限: v-if="userStore.isAdmin"

## 1.4 统一响应处理
{
  code: 1,      // 1=成功, 0=业务失败, 401=未登录/Token过期
  msg: "",      // 错误提示
  data: {}      // 实际数据
}

# 5. 功能硬性要求

## 5.1 性能优化
- 视频列表懒加载: 
  - IntersectionObserver API监听可视区域
  - 进入视口才加载封面图
- 图片懒加载: 
  - v-lazy指令或原生loading="lazy"
  - 占位图(低分辨率模糊版)
- 虚拟滚动: 
  - 长列表(评论/视频列表)使用虚拟DOM
  - 仅渲染可视区域节点
- 防抖节流: 
  - 搜索框输入: debounce 300ms
  - 滚动加载: throttle 500ms
  - 窗口resize: throttle 200ms
- 代码分割: 
  - 路由懒加载 import()
  - 大型组件异步加载

## 5.2 交互细节
- JWT过期处理: 
  - Axios拦截器捕获code=401
  - 清除localStorage Token
  - 跳转/login页面
  - Message.warning("登录已过期,请重新登录")
- 未登录操作引导: 
  - 点击收藏/点赞/投币/评论
  - 弹出Modal对话框(居中,半透明遮罩)
  - 文案:"登录后即可享受完整功能"
  - 按钮:"去登录"(金色) / "稍后"(灰色)
- 接口请求兜底: 
  - 所有API请求catch错误
  - 网络错误: Message.error("网络连接失败")
  - 超时: Message.error("请求超时,请稍后重试")
  - 500错误: Message.error("服务器异常")
- 加载状态反馈: 
  - 按钮: loading旋转图标,禁用点击
  - 表格: Skeleton骨架屏(闪烁动画)
  - 页面切换: 顶部进度条(NProgress)
- 操作确认: 
  - 删除/下架等危险操作: Popconfirm二次确认
  - 文案:"确定要执行此操作吗?"

## 6.2 Axios统一封装
javascript // api/request.js import axios from 'axios' import { useUserStore } from '@/stores/user' import router from '@/router' import { Message } from 'naive-ui'
const request = axios.create({ baseURL: 'http://localhost:8080', timeout: 10000, headers: { 'Content-Type': 'application/json' } })
// 请求拦截: 自动注入Token request.interceptors.request.use( config => { const token = localStorage.getItem('userToken') if (token) { config.headers['User-Token'] = token } return config }, error => Promise.reject(error) )
// 响应拦截: 统一错误处理 request.interceptors.response.use( response => { const { code, msg, data } = response.data if (code === 1) { return data } else if (code === 401) { // Token过期 useUserStore().logout() router.push('/login') Message.warning('登录已过期,请重新登录') return Promise.reject(new Error(msg)) } else { Message.error(msg || '请求失败') return Promise.reject(new Error(msg)) } }, error => { if (error.code === 'ECONNABORTED') { Message.error('请求超时,请稍后重试') } else if (!error.response) { Message.error('网络连接失败') } else { Message.error(服务器错误: ${error.response.status}) } return Promise.reject(error) } )
export default request

<script setup> import { ref, onMounted, onBeforeUnmount } from 'vue' import Artplayer from 'artplayer' import { useVideoStore } from '@/stores/video' const props = defineProps({ src: { type: String, required: true }, poster: { type: String, default: '' }, autoplay: { type: Boolean, default: false }, videoId: { type: Number, required: true } }) const emit = defineEmits(['play-report', 'time-update']) const playerRef = ref(null) let player = null const videoStore = useVideoStore() onMounted(() => { player = new Artplayer({ container: playerRef.value, url: props.src, poster: props.poster, autoplay: props.autoplay, volume: 0.8, playbackRate: [0.5, 0.75, 1, 1.25, 1.5, 2], quality: [ { name: '自动', url: props.src }, { name: '1080P', url: props.src + '?quality=1080' }, { name: '720P', url: props.src + '?quality=720' }, { name: '480P', url: props.src + '?quality=480' } ], theme: '#D4AF37', // 金色主题 lang: 'zh-cn', controls: [ // 自定义控制栏配置 ] }) // 播放记忆 const lastTime = localStorage.getItem(`video_${props.videoId}_time`) if (lastTime && Number(lastTime) > 10) { player.seek(Number(lastTime)) } // 事件监听 player.on('timeupdate', () => { const currentTime = player.currentTime localStorage.setItem(`video_${props.videoId}_time`, currentTime) emit('time-update', currentTime) // 播放超过30秒上报 if (currentTime > 30 && !videoStore.reported[props.videoId]) { emit('play-report', props.videoId) videoStore.markReported(props.videoId) } }) player.on('ended', () => { // 自动连播逻辑 }) }) onBeforeUnmount(() => { if (player) { player.destroy() } }) </script>
<style scoped> .healing-player { width: 100%; aspect-ratio: 16 / 9; background: #000; border-radius: 4px; } </style>
